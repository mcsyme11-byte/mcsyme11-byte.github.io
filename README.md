# Malcolm Syme · Portfolio

**Live:** https://mcsyme11-byte.github.io/

My past projects, current projects and ideas in one searchable place, for university applications and beyond.

## How it's built

Plain HTML, CSS and JavaScript with no build step, hosted free on GitHub Pages. It uses the same "old money" look as the Flight Deck Suite, Hot Mic and NASA Data Projects (navy, brass and cream, serif type), with a modern layout.

| File | What it holds |
|---|---|
| `index.html` | The page: About, Featured, All projects, Skills, Journey, Contact |
| `data/projects.js` | **Every project, skill, stat and timeline entry.** Edit this file to update the site |
| `assets/style.css` | The look |
| `assets/app.js` | Search, filters, project details, animations |
| `assets/emblem.svg` | The emblem and site icon |
| `assets/patches.js` | Draws a mission patch for each project from its `icon` |
| `assets/extras.js` | Live strip, Latest feed, time-of-day sky, Journey route, squawk codes, search (Ctrl K), share, one-page CV |
| `case/*.html` | "How I built it" case studies, generated by `python3 dev/build_cases.py` (edit the text there, then run it) |
| `404.html` | The "Off the chart" page for the whole domain |
| `assets/og-image.png` | The picture shown when the link is shared |

## Live data

The site reads three files from Malcolm's own public sites on the same domain, so no keys are needed. If one is missing, its part simply doesn't show:

- `/flight/data.json`: last flight and sim career (written by Logbook after every flight)
- `/NASA-ESA-Data-and-API-Projects/asteroid-tracker/data/soon.json`: the next close asteroid
- `/Flight-Suite-Releases/catalog.json`: Flight Deck Suite release versions for the Latest feed

The rest of the Latest feed is the `news` list in `data/projects.js`. Add a line there when something ships.

## Hidden extras

- Press **?** for the keyboard shortcuts: **R** opens a random project, **←** and **→** step between projects.

- Type **7700**, **7600** or **1200** anywhere (outside a text box) to change the transponder code.
- `?sky=dawn`, `day`, `dusk` or `night` in the address previews the time-of-day sky.

## Updating a project

1. Open `data/projects.js` and find the project's entry (or copy one to add a new project).
2. Change `status` (`"current"`, `"past"` or `"idea"`), the text, or the links.
3. Set `featured: true` to show it in the Featured section.
4. Update `updated` at the top of the file to today's date.
5. In `index.html`, bump the `?v=` number on the CSS and script links so browsers load the new version.

Each project has its own shareable link: `https://mcsyme11-byte.github.io/#p/<id>` (for example `#p/hot-mic`).
